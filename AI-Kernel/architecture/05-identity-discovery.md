# Identity & Discovery

> **状态**：待完善。本文档目前为架构骨架。

## 1. 定位

负责能力身份的确定与能力来源的接入、搜索、比较、验证和推荐。

## 2. 能力身份

**已确定（ADR-0004）**：能力身份不由系统擅自合并。

能力身份不由名称或代码相似度单独决定。身份的确定需要明确的、可追溯的依据。

身份模型的候选要素（待验证）：

- 显式 Capability ID
- 来源签名 / 发布者身份
- 版本链（版本之间的演进关系）
- 接口契约的兼容性证明
- 多来源证据（Capability Evidence）交叉验证

## 3. 能力来源接入

Capability 可以来自多种来源（见 PROJECT_VISION 第 5 节）：

- Registry（官方 / 第三方 / 社区）
- Git
- 本地文件系统
- 本地进程
- Remote API
- MCP Service
- 现有 AI 工具
- 用户创建的能力

Registry 只是来源，不是能力本身。

## 4. 发现与推荐

系统可以：

- 搜索和索引来源中的能力。
- 比较多个候选能力的接口、质量、可信度。
- 基于 Capability Evidence 验证能力。
- 向用户推荐候选能力。

**用户自主权**：系统只做发现、分析、比较、验证和推荐，是否采用由用户决定。
